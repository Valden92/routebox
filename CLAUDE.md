# Router BOX — инструкции для агентов

Перед работой прочитать корневой `AGENTS.md` и указанные в нём применимые
`.cursor/rules/*.mdc`. `AGENTS.md` — общий источник правил проекта, включая
фичевые ветки от `main`, сохранение работающего VPN, безопасные проверки и GitNexus.

Индексы GitNexus хранятся только локально в `.gitnexus/`. Порядок анализа
и обновления индекса описан в `AGENTS.md`; не генерировать инструкции заново
при обычном обновлении графа.
