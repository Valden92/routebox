# Docs / research

- Единый бэклог приоритетов: `docs/ROADMAP.md`.
- Клиентские идеи из 3x-ui и план внедрения: `docs/research/3x-ui-client-ideas.md`.
- Канвас-обзор в Cursor: `3x-ui-feature-study` (не заменяет markdown в git).
- Проверки реализации определяет [quality.md](quality.md).

Область: `docs/**/*.md`, README, план и интерактивный отчёт.

- Пункт считается сделанным только после слияния в main. Commit, push, review
  и успешные тесты сами по себе не являются завершением.
- Зачёркивать сделанный пункт прямо на его исходном месте в плане, рядом указывать MR.
- Текущий пункт отмечать на его исходном месте: в Markdown — «В работе»,
  в интерактивном отчёте — выделять цветом с подписью текущего состояния.
- Не создавать отдельные списки «сделано/в работе» вместо пометок в самом плане.
- После каждого merge актуализировать канонический `docs/ROADMAP.md` и отчёт;
  исторические доказательства обзора сохранять с указанием даты/коммита.
