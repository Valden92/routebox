# Использование Router BOX

[Быстрый запуск](../README.md#запуск) · [План развития](ROADMAP.md)

## Первый запуск

1. Откройте «Подписки» и добавьте URL, текст, файл или QR-код.
2. Выберите подписку и сервер. Выбор сервера также делает подписку активной.
3. На вкладке «Обзор» включите личный VPN.
4. Во вкладке «Правила» выберите для нужных доменов обычную сеть, системный или личный VPN.

Системный VPN подключается средствами ОС. Router BOX показывает его состояние
и использует для правил, но не управляет подключением.

## Подписки и выбор сервера

- Поддерживаются URL-подписки, ссылки VLESS / Hysteria2 / Shadowsocks,
  текстовые списки, Clash / Mihomo YAML и OpenVPN `.ovpn` со встроенными сертификатами.
- QR-код можно загрузить картинкой или вставить из буфера, без камеры.
- Можно хранить несколько подписок; активна одна. Обновление сохраняет выбранный
  сервер, если он по-прежнему есть в подписке.
- На карточках показаны тип подписки, даты обновления и доступные данные о квоте/сроке.
- Серверы можно сортировать по имени, пингу и частоте выбора.
- «Автовыбор сервера» проверяет заданные сайты до первого подходящего сервера
  или до конца списка. Закрытие окна останавливает подбор.

## Правила и проверка сайтов

Ручные правила задают путь явно. Автоматическое запоминание маршрутов можно
выключить во вкладке «Правила»: сохранённые правила продолжат работать.
Автоматические и ручные правила сворачиваются отдельно. Внутри они собраны
по маршруту: «Личный VPN», «Без VPN», «Системный VPN», затем — по основному
домену. Например, `music.yandex.ru` и `cdn.yandex.ru` находятся в группе `yandex.ru`.
Доменные группы тоже сворачиваются; выбранное раскрытие сохраняется между запусками.
Каждое правило действует самостоятельно: группировка не ограничивает его действие.
Включённые и выключенные правила можно отфильтровать
вместе с маршрутом и поиском по домену. При фильтрации совпадения раскрываются;
после сброса фильтров возвращается прежнее расположение групп.
У правила можно изменить путь или отключить его.

Кнопка «Очистить» рядом с названием секции удаляет её доменные правила после
подтверждения количества. В очистку входят и правила, скрытые поиском/фильтрами.
Правила, появившиеся после открытия окна подтверждения, сохраняются. Если правило
успело перейти в другую секцию, очистка отменяется: закройте окно и подтвердите
её заново. При включённом автоматическом запоминании автоматические правила
могут появиться снова.
Обновление правил не требует переподключения VPN. Уже открытые соединения могут
сохранять прежний маршрут до закрытия.

«Проверка сайта» сравнивает доступность по каждому пути. Во вкладке «Приложения»
можно просмотреть процессы с сетевыми соединениями.

## Закрытие и повторный запуск

Закройте окно: приложение завершит свой демон, личный VPN и собственную
маршрутизацию. Независимый системный VPN продолжит работать. Трея пока нет.
Повторный запуск — `make dev`.

Если завершение не подтвердилось, окно останется открытым. Выполните `make stop`
в папке проекта и повторите закрытие.

## Если что-то не работает

- Если приложение просит настроить хост, выполните `make sync` в папке проекта.
- Если личный VPN не включается, сначала прочитайте ошибку в карточке маршрутизатора.
  Лог sing-box находится в `~/.config/vpn-router/sing-box.log`.
- Если после аварийного завершения пропал интернет, выполните `make recover-network`.
  Команда очищает оставшуюся маршрутизацию Router BOX.
- Настройки и подписки находятся в `~/.config/vpn-router/`.
  Логи могут содержать данные подключения: не публикуйте их целиком.

Для повторной настройки хоста с сохранением подписок:

```bash
make stop
make reset-host
make sync
make dev
```

`make reset-host-wipe` дополнительно перемещает настройки в резервную папку
`*.bak.…`. Используйте только если намеренно хотите начать настройку заново.

Шифрование пока настраивается через API, отдельной формы пароля в UI нет.
Его поведение и ограничения Hysteria2 certificate pin описаны в [безопасности](SECURITY.md).
