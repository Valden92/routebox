# Router BOX

Десктопное приложение для Linux, которое направляет трафик сайтов через обычный
интернет, системный VPN или личный VPN. Можно пользоваться рабочим и личным VPN
одновременно и выбирать маршрут для отдельных доменов.

## Что умеет

- Подключать личный VPN из подписки, ссылки, файла или QR-кода.
- Хранить ручные и автоматические правила для сайтов.
- Подбирать сервер по доступности нужных сайтов.
- Показывать состояние подключений, сетевые приложения и проверять доступность сайта по разным маршрутам.

Системный VPN подключается средствами ОС. Router BOX его не включает и не отключает.

## Требования

Linux с NetworkManager, systemd-resolved, polkit и iproute2; Node.js 20+ с npm.
Для первой установки нужен `sudo`. Остальные зависимости установит `make sync`.
Установка системных пакетов рассчитана на `apt`.

## Запуск

```bash
git clone https://github.com/Valden92/routebox.git
cd routebox
make sync
make dev
```

`make sync` устанавливает зависимости и настраивает систему; при первом запуске
может запросить пароль `sudo`. Для следующих запусков достаточно `make dev`.

В приложении откройте «Подписки», добавьте подписку, выберите сервер и включите
личный VPN на вкладке «Обзор». Во вкладке «Правила» задайте маршруты для сайтов.

При закрытии окна приложение останавливает свой личный VPN и маршрутизацию.
Независимый системный VPN продолжает работать.

## Основные команды

- `make dev` — запустить приложение.
- `make stop` — остановить демон и его маршрутизацию.
- `make check-prereqs` — проверить требования без установки.
- `make recover-network` — восстановить сеть после аварийного завершения.
- `make help` — посмотреть остальные команды.
