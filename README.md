# Router BOX

Десктопное приложение для Linux с трёхуровневой маршрутизацией:

| Путь | Назначение |
|------|------------|
| **direct** | Обычный интернет (Wi‑Fi), без VPN |
| **work** | Системный VPN (NetworkManager, профиль `PTsecurity` → `tun0`) — только из ОС |
| **personal** | Личный VPN из подписки (VLESS / Hysteria2 через sing-box) |

## Возможности

- Статус интернета, системного VPN (только просмотр) и личного VPN
- Локальный маршрутизатор (`tun100`): пока приложение запущено, трафик идёт через правила
- Режимы **обычный** и **совместно с системным VPN** (coexist: изоляция `tun0`, outbound `work`, DNS)
- Автопереключение режима при появлении/пропадании системного VPN
- Автообучение доменов по живому трафику и истории браузера (приоритет: обычная сеть → системный VPN → личный)
- Правила доменов: авто и ручные, поиск, смена пути, вкл/выкл
- Вкладка приложений: скан процессов с сетью
- Системный VPN включается в NetworkManager (MFA в системе), приложение им не управляет
- Несколько подписок (одна активная), автообновление интервала, подсветка выбранной
- Список серверов, TCP‑пинг через основной интерфейс, сортировка (имя / пинг / часто выбираемые)
- Сохранение выбранного сервера; при refresh — перепривязка или сброс, если узел исчез
- Проверка доступности сайта по каждому пути
- Шифрование конфига паролем (API `/api/lock`, `/api/unlock`)

## Требования

- Linux с NetworkManager (Debian/Ubuntu для автоматической установки системных libs)
- Node.js 20+ в PATH (`node` / `npm`) — остальное ставит `make sync`

## Быстрый старт

```bash
make sync      # зависимости + настройка TUN/NM (sudo при первом запуске)
make dev       # демон + UI
```

Первый раз удобнее: `make dev-full` (= `sync` + `dev`).

Остановка демона: `make stop`.  
Конфиг: `~/.config/vpn-router/`, API: `http://127.0.0.1:47891`

Личный VPN включается в UI **без пароля** — права выдаются при `make sync`.  
Пароль системы может понадобиться только в терминале во время `sync` (apt и настройка хоста).

### Маршрутизатор и личный VPN (sing-box / TUN)

Пока приложение запущено, маршрутизатор держит `tun100` и применяет правила.  
Кнопка личного VPN включает/выключает outbound `proxy`, а не весь маршрутизатор.

Если в UI «включён», но статус «Выключен» — перезапустите демон (`make stop && make dev`) и смотрите лог: `~/.config/vpn-router/sing-box.log`.  
Если карточка просит `make sync` — выполните его в каталоге проекта (или `make configure-host` для повторной настройки).

**Если пропал интернет** после работы с личным VPN / маршрутизатором (sing-box упал, маршруты остались):

```bash
make recover-network
# или: make stop   (гасит демон и sing-box)
```

При аварийном завершении sing-box маршруты могут «залипнуть» — лучше останавливать через UI или `make stop`, а не убивать процесс насильно.

### Что делает `make sync`

Проверяет и при необходимости ставит (уже установленное не трогает лишний раз):

- системные пакеты Tauri (`apt`, `sudo` если чего-то не хватает)
- **sing-box** в `~/.local/bin`
- **настройка хоста** (`setcap` на sing-box + drop-in NetworkManager для TUN, один `sudo` если ещё не сделано)
- Go (в `~/.local/go`, если `go` нет в PATH)
- Rust/cargo (через `rustup`, если нет)
- `go mod download`, `npm install`, `cargo fetch`

```
└─────────────────┘               │  nmcli, ping,    │
                                  │  subscriptions   │
                                  └────────┬─────────┘
                                           │
                    ┌──────────────────────┼──────────────────────┐
                    ▼                      ▼                      ▼
              Wi-Fi direct            tun0 (work)            sing-box tun100
```

|---------|------------|
| `make lint-tools` | golangci-lint + npm (ESLint/Prettier) |
| `make lint` | golangci + ESLint + clippy |
| `make check-fmt` | проверка формата (gofmt / Prettier / rustfmt) |

| `make test` | `go test ./tests/... ./internal/...` |

CI (GitHub Actions): параллельно **Lint**, **Format**, **Test** на push/PR  
(`.github/workflows/lint.yml`, `format.yml`, `test.yml`).

Юнит-тесты живут в корневом `tests/` (black-box по пакетам). Package-local `*_test.go` — исключение (доступ к unexported).

Конфиги: `.editorconfig`, `.golangci.yml`, `desktop/eslint.config.js`, `desktop/.prettierrc.json`, `desktop/src-tauri/rustfmt.toml`.  
Правила для агентов/IDE: `.cursor/rules/` (Go, тесты, UI). Для `*_test.go` — отдельные линтеры (`thelper`, `tparallel`) и смягчённые правила.

## Безопасность

Подписки и URI хранятся локально в `~/.config/vpn-router/subscriptions/`.  
Для шифрования настроек: `POST /api/lock` с `{"passphrase":"..."}`.
